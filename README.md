# Howard's Lantern: architecture at a glance

How [howardslantern.com](https://howardslantern.com) is built: a React app on
Cloudflare Pages, one Cloudflare Worker behind `/api/`, D1, and an ask box
that answers from each state's driver's manual with hybrid retrieval (BM25 +
vector search) and Claude.
